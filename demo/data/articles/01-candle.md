光从窗缝里进来，落在纸的左上角。它不照亮整间屋子，只照亮正在写的那一行——这大概就是一支蜡烛的算术。

## 一 · 纸

纸是光的容器。它把多余的光吸进去，再把剩下的还给你。

| 时辰 | 光的长度 | 备注 |
| --- | --- | --- |
| 卯 | 三尺 | 窗未开 |
| 午 | 五尺 | 正照在砚台上 |
| 酉 | 一尺 | 只够写完最后一行 |

## 二 · 数

先记下一行式子，像把灯芯剪短一点：

```js
const lamp = {
  light: (hours) => hours * 0.618,
  ink: (lines) => lines + 1,
};
```

它并不解释什么，只是让纸上的空白有个尺度。相对论也一样：

$E = mc^2$

$$\int_0^1 x^2\,dx = \frac{1}{3}$$

## 三 · 余烬

写完以后，把烛芯按进沙里。第二天的纸会记得那一点点黑。
