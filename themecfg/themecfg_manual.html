怎么改：在 BBG 的“配置第三方主题”中编辑 themecfg/themecfg.json，保存后刷新预览。没有写的键使用内置默认值；JSON 写坏时主题退回默认值并在控制台提示。

站点设置里不生效的三项：标题栏背景颜色、标题栏文字颜色、链接颜色；本主题使用自己的版式与色板。链接色请改 外观.链接颜色 / 外观.链接颜色（暗色）。live2d 也不会加载；需要时用“自定义 JS”。

外观

键取值说明
默认模式auto / day / night首次访问的明暗模式；auto 跟随系统。右上角按钮随时切换并记住选择。
链接颜色CSS 颜色，留空为默认亮色模式链接色；建议选深色以保证对比度。
链接颜色（暗色）CSS 颜色，留空为默认暗色模式链接色；建议选浅色。
版心宽度（rem）0 或 32..440 跟随站点设置“使版心宽度更窄”（36/40rem）；填数字则强制覆盖。
首字下沉true / false文章首段首个汉字/字母放大；标点开头不下沉。
显示页边目录true / false宽屏文章页右侧页边目录；不足 3 个标题时不显示。
界面使用衬线null / true / falsenull 跟随站点设置“优先使用衬线字体”；true/false 强制。

窗光（WebGL）

键取值说明
启用true / false关闭后不创建 WebGL 上下文、不显示灯按钮，也没有 CSS 光晕。
强度0..1光束、尘埃与暗角的总体透明度；默认 0.55。
粒子密度0..1尘埃微粒密度；默认 0.5。
帧率上限30 / 45 / 60越低越省电；其他值按 60。
默认开启true / false首次访问是否亮灯；右上角灯按钮可切换并记住。

低电量设备建议：强度 0.3、帧率上限 30。prefers-reduced-motion 会只渲染静止一帧；WebGL 不可用时自动退回 CSS 光晕，正文不受影响。

阅读

  • 显示阅读时长：true/false，文章头显示“约 N 分钟”。

可覆盖的界面文本键

在站点设置“自定义界面文本”中启用并添加 key/value，可覆盖：NAV_ARTICLES、NAV_ARCHIVE、NAV_FRIENDS、SEARCH、SEARCH_PLACEHOLDER、NO_RESULTS、PINNED、PAGE_PREV、PAGE_NEXT、READ_TIME、REVISED、PREV、NEXT、REFERENCES、INFO、WARNING、DANGER、SUCCESS、COMMENTS、COMMENTS_UNAVAILABLE、COMMENTS_LOAD_FAILED、COMMENTS_PREVIEW、LICENSE、DOWNLOAD、COPY、COPY_CODE、COPIED、SHARE、LINK_COPIED、NOT_FOUND、PASSWORD_PROMPT、PASSWORD_SUBMIT、PASSWORD_WRONG、LIGHT_ON、LIGHT_OFF、THEME_DAY、THEME_NIGHT、TOC、BACK_TO_TOP、ANNOUNCEMENT、LOADING、LOAD_ERROR、MINUTES、EMPTY、TAG_TITLE、CLOSE。
